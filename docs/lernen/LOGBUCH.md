## Etappe 3 und 4 (teilweise): Spring Boot, Datenbank, M1 (07.10.2026)

- **Entstanden:**
  - `backend/` über start.spring.io: Spring Boot 4.1.1, Java 25, Gradle 9.7.1 (Wrapper). Abhängigkeiten aus AUFTRAG.md, Abschnitt 5, ohne Security.

  - `backend/src/main/resources/application.yml`: `.env`-Import, Datasource, Hikari (max. 5), `ddl-auto: validate`, Port `${PORT:8080}`, Actuator nur `health`.
  - `application-dev.yml` + `bootRun` mit Profil `dev`: SQL-Log (`org.hibernate.SQL`, Parameter über `org.hibernate.orm.jdbc.bind`).
  - `db/migration/V1__create_product.sql` (Beispiel), `V2__create_list_item.sql` (**vom Team geschrieben**).
  - `product/Product.java`, `product/ProductSource.java` (Beispiel-Entity), `shopping/ListItem.java` (**Felder vom Team**).
  - `shopping/ListItemRepository.java`, `ListItemService.java`, `ListItemResponse.java` (DTO als Record), `ListItemController.java` mit `GET /api/list-items`.
  - Tests: `KorbgeldApplicationTests` (Testcontainers, `postgres:17`, `disabledWithoutDocker`), `shopping/ListItemControllerTest` (`@WebMvcTest`, MockMvc, Mockito).
  - `docs/lernen/DATENBANK.md`: Spickzettel zu Anbindung, Verwaltung und Beobachtung.
- **Konzepte:** Inversion of Control, Dependency Injection per Konstruktor, Auto-Configuration (`@ConditionalOnClass`, `@ConditionalOnMissingBean`), `@ConfigurationProperties`, DataSource und Hikari-Pool, JDBC-URL, Flyway (Versionsnummern, Prüfsumme, `flyway_schema_history`, Transaktion bei Fehlern), `ddl-auto: validate`, `@Entity`, `@Id`, `@GeneratedValue(IDENTITY)`, `@ManyToOne` + `@JoinColumn`, `@Enumerated(STRING)`, Spring-Data-Repository als Interface, abgeleitete Abfragen aus Methodennamen, `@EntityGraph` gegen das N+1-Problem, `@Transactional(readOnly = true)`, DTO statt Entity, Jackson, `@WebMvcTest` mit Attrappe (`@MockitoBean`), `jsonPath`, Gegenprobe bei Tests.
- **Verfolgter Request:** `GET /api/list-items` → Controller → Service → Repository → ein SELECT mit JOIN (im SQL-Log gesehen) → JSON mit 3 Testeinträgen, `createdAt` in UTC (`Z`).
- **Lektionen:**
  - SQL hat Dialekte: `AUTOINCREMENT` (SQLite) gibt es in Postgres nicht, dort heißt es `GENERATED BY DEFAULT AS IDENTITY`.
  - IDs und Fremdschlüssel sind `BIGINT` (Java `Long`). Sonst bricht `validate` ab.
  - `TIMESTAMP WITH TIME ZONE` ↔ `Instant`: eindeutige Zeitpunkte, auch auf UTC-Servern.
  - Eine noch nicht committete Migration durfte lokal zurückgesetzt werden. Nach dem Commit nur noch eine neue Migration.
  - Bei Spring-Fehlern das unterste `Caused by:` lesen.
  - `gradlew` braucht unter Git das Ausführungsrecht (`100755`), sonst scheitert Linux-CI.
